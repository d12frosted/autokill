# 0002. Where mob data comes from

## Status

Accepted

## Context

Two facts are needed and neither is in the game's data files: which mobs drop which
items, and where those mobs stand. Loot tables live on the server, and mobs are spawned
by the server, so there is no sheet to read.

Three community sources were measured:

| source | drop items | mobs with positions | positions per mob |
|---|---|---|---|
| Garland Tools | 188 | none | n/a |
| FFXIV Teamcraft | 237 | 2,333 | ~44 |
| LuminaSupplemental | 342 | 10,475 | ~2.5 |

Garland and Teamcraft disagree about which half of the game they cover: their drop tables
overlap on only 130 items. Garland alone claims Endwalker has almost nothing, which is
wrong; Almasty Fur in Garlemald is an ordinary crafting material it has no record of.

LuminaSupplemental (sourced from the Lodestone, Gubal and community collection) is
broader than both on drops, and knows where five times as many mobs live, but knows very
little about each one.

## Decision

Ship LuminaSupplemental as the primary source, consumed as a NuGet package so it updates
without work here. It also carries BNpcBase ids, which are what `IBattleNpc.DataId`
returns, so targeting compares integers rather than matching names.

Supplement it with a Teamcraft-derived position extract, generated by `tools/data` and
embedded in the assembly as 182 kB of gzipped JSON. Both feed one clustering pass.

Each of those positions carries the level it was recorded at, which no other source has.
Levels belong to the point rather than to the mob: one name covers creatures forty levels
apart, and a fifth of the recorded places hold more than one level themselves. A level of
zero means unrecorded, which the LuminaSupplemental half always is.

The extractor stays in the repository rather than being run once and forgotten, so the
embedded data can be regenerated when upstream improves.

## Consequences

- 9,753 mobs are farmable and 307 droppable items are reachable, neither of which either
  source reaches alone.
- Density matters more than breadth for choosing a place to stand, and that is exactly
  where the smaller source wins, so both are needed.
- Coverage is partial and always will be, because all of it is crowd sourced. A mob with
  drops but no known position is still indexed and shown, marked as having nowhere to go,
  because that is more use than an empty result.
